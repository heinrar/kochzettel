Rezeptbuch

Erzeugt ein druckfertiges Buch aus allen gespeicherten Rezepten. Jedes Rezept wird — wo möglich — automatisch auf eine A5-Seite eingepasst (die Schrift wird dafür bei Bedarf etwas verkleinert); passt ein Rezept auch dann nicht, wird es auf zwei A5-Seiten aufgeteilt, die gemeinsam auf ein A4-Blatt (Querformat) gedruckt werden.
